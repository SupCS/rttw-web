# wealthy — прогресс

Обычный сайт с общей серверной базой. Требует входа и подключения; офлайн-режим и синхронизация локальных баз не нужны.

## Готово

- [x] Название wealthy во всём интерфейсе, текстах en/uk/ru, заголовке вкладки, манифесте приложения и именах скачиваемых резервных копий.
- [x] Мобильный редизайн Midnight: новая навигация, карточки валют, нижние панели, цифровая клавиатура, переработанные экраны. Дизайн подключён к существующему API; демоданные и Sites-конфигурация исключены.
- [x] Упрощены формы: категории и подкатегории в сетке без горизонтальной прокрутки и дублирующего списка; клавиатура закреплена снизу и сворачивается стрелкой, поля прокручиваются отдельно; новые операции без отдельного поля заметок (старые сохранены); одно название категории; создание домохозяйства только на вкладке домохозяйства.

- [x] Мультивалютные счета, начальные остатки, личные/общие счета; тип счёта в карточке, общий баланс без даты. Удаление вместо архива: исключение остатка или атомарный перенос всех валют/долгов; история сохранена, будущие платежи отменяются.
- [x] Категории/подкатегории, цвета и SVG-иконки, удаление с сохранением истории и объединение. Старые архивные записи доступны в обычных списках.
- [x] Операции и splits, переводы/комиссии, редактирование/копирование/удаление/отмена, поиск и фильтры.
- [x] Личная/семейная аналитика: день, неделя, месяц, год и произвольный диапазон; недели/годы переключаются стрелками. Единые даты для итогов, диаграмм и прогноза; длинные диапазоны отображаются целиком. Явный выбор «В одной валюте» / «Отдельно по валютам» с пояснениями. Дублирующая вкладка балансов убрана.
- [x] Курсы/история/калькулятор, FX-снимки; самостоятельные повторяющиеся платежи с предпросмотром дат, паузой и остановкой.
- [x] Вход через cookies, семейные приглашения, серверный JSON export/preview/restore.
- [x] Три языка, 12 тем, адаптивность; подготовлены Dockerfile и railway.toml.

Проверки: `npm run check`; точечные сценарии удаления в `apps/api/test/deletion.test.ts` и расчётов в `apps/web/src/data/derived.test.ts`.

## Запуск

Node.js 22.13+. Из этой папки:

```powershell
npm install
npm run api:local
```

Во втором терминале: `npm run dev`. Сайт: `http://127.0.0.1:5173`. Локальная серверная база: `.local-data` в корне проекта; production PostgreSQL задаётся через `apps/api/.env` по `.env.example`.

Обычная итоговая проверка: `npm run check` (инструкции и TypeScript). Полные тесты доступны вручную: `npm test` или `npm run check:full`. Сборка: `npm run build`; проверка работающего локального API: `npm run smoke:online`.

Проект уже находится в `E:\rttw-web`. Для размещения нужны новая PostgreSQL-база, DATABASE_URL и HTTPS WEB_ORIGIN; старый Railway не менять.
